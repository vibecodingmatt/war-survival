# Gameplay reference

Place the gameplay video in this folder. For example:

`war-survival/references/gameplay/gameplay-reference.mp4`

The original filename is also fine. Add any related screenshots or notes here.
If only part of the video matters, include the relevant timestamps in your notes.

These files are development references, not game assets. Everything in this
folder except this README is ignored by Git so large recordings are kept out of
the future repository. The reference video will guide the first playable build.
